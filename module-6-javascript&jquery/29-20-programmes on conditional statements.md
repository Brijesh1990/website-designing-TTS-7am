# write all the programmes using conditions statements 

1. Check if a number is positive, negative, or zero

Write a program to check whether a number is positive, negative, or zero.

2. Even or odd

Write a program to check if a number is even or odd.

3. Largest of two numbers

Write a program to find the larger number between two numbers.

4. Largest of three numbers

Write a program to find the largest among three numbers.

5. Divisible by 5

Write a program to check if a number is divisible by 5.

6. Leap year

Write a program to check whether a given year is a leap year or not.

7. Grade calculator

Write a program that assigns grades based on marks:

90+ → A
75–89 → B
50–74 → C
Below 50 → Fail
8. Vowel or consonant

Write a program to check whether a character is a vowel or consonant.

9. Voting eligibility

Write a program to check if a person is eligible to vote (age ≥ 18).

10. Multiple of 3 and 7

Write a program to check if a number is divisible by both 3 and 7.

11. Simple calculator (switch)

Write a program that performs addition, subtraction, multiplication, or division based on user input using switch.

12. Number in range

Write a program to check if a number lies between 10 and 50.

13. Palindrome number

Write a program to check whether a number is a palindrome.

14. Login validation

Write a program to validate username and password using conditional statements.

15. Traffic light system

Write a program to display actions based on traffic signal colors (red, yellow, green).

16. Valid triangle

Write a program to check if three angles form a valid triangle.

17. Smallest of three numbers

Write a program to find the smallest among three numbers.

18. Prime number

Write a program to check whether a number is prime.

19. Discount calculation

Write a program to apply a 10% discount if the purchase amount is greater than 1000.

20. Password strength

Write a program to check whether a password is strong (minimum 8 characters).
